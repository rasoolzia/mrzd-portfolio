# Interactive Portfolio Website

A personal portfolio built with React, TypeScript and Tailwind CSS.

The project showcases my experience, skills and projects through a terminal-inspired interface where visitors can explore information using commands, similar to a real shell experience.

## Features

- Interactive terminal interface
- Custom commands and command history
- Responsive design
- Smooth animations with Tailwind CSS
- Project showcase
- Experience and skills sections
- Modern React architecture

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide Icons

## Purpose

This project focuses on creating an engaging developer portfolio with a unique user experience rather than a traditional static website.
